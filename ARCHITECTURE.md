## Data Flow

### 1. Initial Load
```
User Opens Calendar
        ?
Calendar.razor loads
        ?
OnInitializedAsync() called
        ?
LoadEvents() method
        ?
Calculates date range based on view
        ?
Calls CalendarService.GetEventsAsync(start, end)
        ?
Service loops through all Calendar IDs
        ?
For each calendar:
  ? Builds API URL with parameters
  ? Makes HTTP GET request
  ? Parses JSON response
  ? Converts to CalendarEvent objects
        ?
Merges all events
        ?
Sorts by start time
        ?
Returns to component
        ?
Component updates UI
        ?
User sees events
```

### 2. View Change
```
User clicks "Week" button
        ?
ChangeView(Week) method
        ?
Updates ViewType property
        ?
Calls LoadEvents()
        ?
[Same flow as Initial Load]
```

### 3. Navigation
```
User clicks "Next" button
        ?
NextPeriod() method
        ?
Calculates new date:
  • Day: +1 day
  • Week: +7 days
  • Month: +1 month
        ?
Calls LoadEvents()
        ?
[Same flow as Initial Load]
```

### 4. Event Details
```
User clicks on event
        ?
ShowEventDetails(event) method
        ?
Sets selectedEvent = event
        ?
Component re-renders
        ?
Modal appears with event details
        ?
User clicks outside or X button
        ?
CloseEventDetails() method
        ?
Sets selectedEvent = null
        ?
Modal disappears
```

## View Responsibilities

### DayView.razor
- **Input**: List of events, current date
- **Display**: Vertical list of events
- **Shows**: Time, title, location
- **Output**: Event click ? raises OnEventClick

### WeekView.razor
- **Input**: List of events, week start date, week start day
- **Display**: 7-column grid
- **Shows**: Day headers, event titles, event times
- **Output**: Event click ? raises OnEventClick

### MonthView.razor
- **Input**: List of events, current date
- **Display**: Calendar grid with day cells
- **Shows**: Day numbers, event titles (max 3 + "more")
- **Output**: Event click ? raises OnEventClick
- **Logic**: Calculates full calendar (includes prev/next month days)

## API Request Format

```
GET https://www.googleapis.com/calendar/v3/calendars/{calendarId}/events
  ?key={apiKey}
  &timeMin={startDateTime}
  &timeMax={endDateTime}
  &singleEvents=true
  &orderBy=startTime

Response:
{
  "items": [
    {
      "id": "event123",
      "summary": "Event Title",
      "description": "Event description...",
      "location": "123 Main St",
      "start": {
        "dateTime": "2024-01-15T14:00:00-06:00"
      },
      "end": {
        "dateTime": "2024-01-15T15:00:00-06:00"
      }
    }
  ]
}
```

## Error Handling

```
Try to fetch events
  ??? Success ? Parse and display
  ?
  ??? Failure
      ??? Log to console
      ??? Continue with other calendars
      ??? Display what we have
          ??? Some calendars succeeded ? Show those events
          ??? All failed ? Show "No events"
```

## Future Enhancement Points

1. **Caching Layer**
   - Cache events in browser storage
   - Reduce API calls
   - Improve performance

2. **OAuth 2.0**
   - User authentication
   - Access private calendars
   - Token management

3. **Event Colors**
   - Per-calendar colors
   - Color picker in settings
   - Category-based colors

4. **Filtering**
   - Toggle calendars on/off
   - Filter by keyword
   - Filter by date range

5. **Offline Support**
   - Service worker caching
   - IndexedDB storage
   - Sync when online
